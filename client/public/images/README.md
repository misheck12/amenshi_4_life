# Image Placeholders Guide

Place your images in this directory:

## Structure:
```
public/images/
├── hero-bg.jpg           # Homepage hero background
├── about-us.jpg          # About page main image
├── mission.jpg           # Mission section
├── wells.jpg             # Water wells ministry
├── babies.jpg            # Somone House babies
├── education.jpg         # Education program
└── gallery/              # Gallery images
    ├── 1.jpg
    ├── 2.jpg
    └── ...
```

## Recommended Sizes:
- **Hero Background**: 1920x1080px (landscape)
- **Section Images**: 800x600px
- **Team Photos**: 400x400px (square)
- **Gallery**: 800x800px (square)
- **Project Images**: 800x600px (landscape)

## Image Optimization:
- Use JPEG for photos
- Compress to 80-90% quality
- Use WebP format for better performance (optional)

## Tools:
- **TinyPNG**: https://tinypng.com
- **Squoosh**: https://squoosh.app

## Note:
The app will show placeholder gray boxes if images are missing.
Add your real images here to see them on the website!
